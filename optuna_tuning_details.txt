\section{Optuna Hyperparameter Tuning Strategy}

As an alternative to the custom dynamic grid search, we can optimize the standard SVM parameters ($C$ and $\gamma$) alongside our custom sample-wise weighting parameter ($a$) using Optuna. Optuna is an automated hyperparameter optimization framework that employs the Tree-structured Parzen Estimator (TPE) algorithm to efficiently explore the parameter space using Bayesian optimization.

### 1. Parameter Search Spaces

Instead of manually defining expanding grids, we define bounded probabilistic search spaces from which Optuna samples values. The TPE algorithm dynamically focuses the search on regions of the space that yield higher validation scores.

1. **Standard SVM Parameters ($C$ and $\gamma$):**
   Because $C$ and $\gamma$ are highly sensitive to orders of magnitude, we sample them from a logarithmic continuous distribution.
   - $C \sim \text{LogUniform}(10^{-6}, 10^{3})$
   - $\gamma \sim \text{LogUniform}(10^{-6}, 10^{2})$ for RBF and $\gamma \sim \text{LogUniform}(10^{-6}, 10^{-1})$ for polynomial kernels. 

2. **Kernel Selection:**
   We individually tune with Optuna for 4 different kernels and select the best kernel. The 4 kernels we use are linear, RBF, degree-2 polynomial and degree-3 polynomial. 

3. **Sample-wise Weights ($a$ parameter):**
   We handle class imbalance identically by weighting the dual formulation bound $C \times r_i$. The minority and majority class weights are controlled by a single parameter $a$, where:
   
   $$a = \frac{1}{2r_+} = 1-\frac{1}{2r_-}$$
   
   Since $a$ must strictly satisfy $0 < a < 1$ to maintain valid positive weights, we sample $a$ from a continuous linear distribution across the valid mathematical range. To anchor the search slightly, the sampler can be seeded or biased around the theoretical baseline $\Bar{a} = \frac{n_+}{n}$.
   - $a \sim \text{Uniform}(0.0001, 0.9999)$

### 2. Optimization Mechanism

The optimization process operates over a predefined number of trials (we use 80 trails for each kernel) through a defined objective function:

1. **Objective Function Evaluation:**
   For each trial, Optuna suggests a configuration of $(C, \gamma, \text{kernel}, a)$. The SVM model is instantiated with the suggested parameters and trained using the sample weights derived from $a$. The model is then evaluated on both the training and validation sets. The best model is evaluated based on the F1 score for switch-class prediction. 
   
3. **Bayesian Updates (TPE Sampler):**
   After evaluating a configuration, the TPE algorithm updates its internal probabilistic models using the objective score. It builds two density functions: one for configurations that yield high objective scores, and one for low scores. Subsequent trials prioritize sampling from regions where the ratio of these two densities is highest. As a result, Optuna instantly learns that overly complex regions (e.g., excessively high $C$ or $\gamma$) yield lower objective scores and autonomously steers the search back toward regularized, safer parameters.
